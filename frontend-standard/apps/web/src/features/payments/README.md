# payments · web

Backend owner: **Payment**. Contract + Deposit + Dispute, state từ backend; không thanh toán tiền lúa.

- `pages/`: màn hình điều phối UI.
- `components/`: component riêng module trên nền tảng này.
- `hooks/`: query/mutation và state điều phối.
- DTO/schema: `packages/contracts`; request: `packages/api-client`.

Đọc docs/04_MODULES_VA_CHIA_VIEC.md và docs/05_LUONG_CODE_MAU.md trước khi code. Những mục ngoài ví dụ User/Trading hiện là chỗ đặt code, chưa có API/CRUD.
